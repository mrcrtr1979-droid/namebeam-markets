What the live card does and does not do

  • The live card requests the public explorer file when the page opens. The saved file was 201,285 bytes on 2026-11-24. The request omits credentials and the referrer.
  • It shows no business name and no provider answer text.
  • If counts are unavailable, the card shows a status message.
