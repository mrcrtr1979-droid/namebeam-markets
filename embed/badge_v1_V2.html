What the badge reads and what it leaves out

  • It prints counts and dates from the public file: the number of sources with a positive answer-day count in the file, the largest answer-day count reported for one source in the window, and the end date of the source window.
  • It prints no business name and no provider answer text.
  • It loads no script, font, image or cookie. The links carry campaign tags.
  • This snapshot shows the source window and the embed build date. Rebuild it from a newer source file to refresh it. It does not update itself.
