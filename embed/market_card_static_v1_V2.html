What a card shows and what it leaves out

  • It shows, for each source, the answer days in the window and the number of selected entries named on at least one answer day. These are counts.
  • It shows no business name and no provider answer text.
  • This snapshot shows the source window and the embed build date. Rebuild it from a newer source file to refresh it, or use the live card, which requests the public file when the page opens. It does not update itself.
