Answers and sources: tanning salons in four markets

Sample cut from NameBeam Edition 1. Fixed local questions asked once a day through each engine API (ChatGPT, Claude, Gemini, Perplexity); Google rows are Google search results (Google SERP: AI Overview and organic results), not an engine API call. Engines are never pooled with each other. A panel is one market plus one niche. An answered day is a day on which one engine returned a non-empty name list for one panel; it counts as naming a business when at least one name survives the Edition 1 name gate. Counts use the Edition 1 name gate and the N.gated.day metric exactly as published (README, metrics/metrics_v2_methods.csv); a spot audit found 86 of 100 gated names to be operating businesses.

Coverage

  • WA, 2026-09-01 to 2026-09-27: Perplexity ran on Sonar chat completions with web search.
  • WB, 2026-09-28 to 2026-10-13: Perplexity ran on the Agent API with a forced web search tool. Perplexity retired Sonar chat completions on 2026-09-27, so WA and WB are reported apart and never pooled; any change between them mixes the method change with change over time. WB is a short window: read its values with their denominators.
