How it was built

One fixed question per business or segment goes to each engine every day, and each answer is stored as a raw file with its SHA-256. The settings of every engine are in the method note. Read the method.

Verify it yourself

The pack ships with verify.py (no packages beyond the Python standard library) and MANIFEST.sha256. In the downloaded folder run:

python3 verify.py              # every file against MANIFEST.sha256
python3 verify.py --rebuild    # also rebuild the answers table from the raw answers
python3 verify.py --metrics    # also recompute the metrics table

It prints MATCH or MISMATCH for every file and ends with VERIFY MATCH when everything checks. Exit code 0 means every file matched.
