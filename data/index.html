Live JSON files

Two public JSON files need no key and no account. On 2026-11-23, both returned HTTP 200 with Content-Type: application/json and Access-Control-Allow-Origin: *.

explorer_data.json (schema v3). In the snapshot read on 2026-11-23, the file's overall window fields were 2026-08-05 and 2026-11-22. It contained 92 market-and-niche cells across 27 markets. The file provides answer-day counts by engine for OpenAI, Perplexity, Gemini and Anthropic, and shows up to ten counted business names per cell. The method_note field explains that a business counts for an engine on each answer day when the saved text mentions its full name as whole words. The mention share uses that engine's own answer days as the denominator. These counts measure mentions in saved text.

latest.json. The snapshot read on 2026-11-23 was generated on 2026-11-23 at 12:41 PM CT and lists 2026-11-22 as its latest run day. It contained 33 market-and-niche records with run days, total rows and OK rows. The per-engine fields give total rows, OK rows and days with OK rows. Across all records, the snapshot reported 14,902 rows and 12,331 OK rows.

Source: https://namebeam.ai/data/explorer_data.json and https://markets.namebeam.ai/data/latest.json, read 2026-11-23 10:57 PM CT.
