How much do recorded AI name lists repeat on consecutive run days?

We compared the same engine's answers to the same fixed question in the same market on adjacent run days. The record spans 2026-09-28 to 2026-11-23, with no run on 2026-10-05. Lists include directories and other non-business names.

For each pair, overlap is the number of distinct normalized names in both lists divided by the number in either list or both. Mean overlap averages that value across evaluated pairs. Identical means the same set in any order. One empty list gives zero overlap. Pairs with two empty lists are excluded.

  • Claude, 2026-09-28 to 2026-11-23: 1,952 pairs, mean overlap 0.454. Identical: 378 (19.4%). None shared: 402 (20.6%). Lists averaged 3.8 names.
  • OpenAI, 2026-09-28 to 2026-11-09: 1,186 pairs, mean overlap 0.208. Identical: 7 (0.6%). None shared: 370 (31.2%).
  • OpenAI, 2026-11-10 to 2026-11-23: 650 pairs, mean overlap 0.262. Identical: 2 (0.3%). None shared: 36 (5.5%). On 2026-11-10 we changed which model we ask.
  • Perplexity, 2026-09-28 to 2026-11-23: 2,992 pairs, mean overlap 0.235. Identical: 57 (1.9%). None shared: 709 (23.7%).
  • Gemini, 2026-10-21 to 2026-11-23: 1,343 pairs, mean overlap 0.158. Identical: 0 (0.0%). None shared: 114 (8.5%).

The rows describe different windows and question mixes. Of 2,126 Gemini rows collected from 2026-09-28 to 2026-11-23, 684 were excluded for run status.

Keeping names recorded in one market gave mean overlaps from 0.137 to 0.369 across these rows in the 2026-09-28 to 2026-11-23 collection window. On the same Perplexity anchors, mean overlap was 0.225 at one calendar day and 0.134 at 28 days, with endpoints spanning 2026-09-29 to 2026-11-23.

We used fixed API prompts. Pairs are not independent. Consistency is not accuracy. Perplexity results are reported as counts and rates. CC BY 4.0 covers this compilation and its derived columns. Provider answers and search-result rows are outside that license.

What the run-to-run consistency counts do not show

Collection window: 2026-09-28 to 2026-11-23. Consecutive pairs use adjacent run days. There was no run on 2026-10-05.

Consistency is not accuracy

These counts measure overlap in machine-extracted, recorded name lists. The lists can include directories, headings, associations and place names, and extraction can miss names. We did not verify whether recorded names identify real businesses, fit the question, or are good choices.

Name rules and denominators

The main rule cleans accents, selected punctuation and whitespace, lowercases ASCII tokens, removes the, and, llc, inc, corp, ltd, pllc and pc, and joins the remaining letters and digits. Identical means the same normalized name set in either order. A pair with one empty set has zero overlap. A pair with two empty sets is excluded.

In the 2026-09-28 to 2026-11-23 collection window, the displayed engine means using exact cleaned strings differ by at most 0.003 from the displayed main-rule means. Restricting names to those recorded in one market among OK run-1 rows gives mean overlaps from 0.137 to 0.369. This can remove a genuine business that appears in multiple markets and retain a directory that appears in one. It changes the denominator: double-empty exclusions rise to 851 for Claude, 214 for OpenAI through 2026-11-09 and 9 from 2026-11-10, 22 for Perplexity and 7 for Gemini.

Fixed prompts and sample

The analysis uses scheduled run-1 API responses to fixed trade-and-market prompts. Real users can phrase questions differently, and consumer-app results can differ. From 2026-09-28 to 2026-11-23, there were 70 Perplexity series and 50 for each other engine, covering 16 trades and 19 markets. Series enter this window on 2026-09-28, 2026-10-08 or 2026-10-30. The market mix varies by trade. A trade represented in one market cannot be separated from that market here.

Our market labels for the 2026-09-28 to 2026-11-23 collection window assign 12 markets to large cities over 250,000, 5 to mid-size cities from 50,000 to 250,000, and 2 to small town or county. These are intended as approximate 2020 Census city-proper bands. Census assignments remain pending verification.

Pairs are not independent. Adjacent pairs can share a run day, markets repeat across trades and engines, and each evaluated pair receives equal weight. The counts are descriptive and carry no intervals.

Exclusions and model records

From 2026-09-28 to 2026-11-23, Gemini had 684 not-OK rows out of 2,126 (680 failed and 4 quota blocked). From 2026-09-28 to 2026-10-20, 9 of 606 rows were OK. From 2026-10-21 to 2026-11-23, 87 of 1,520 rows were not OK (83 failed and 4 quota blocked). On 2026-11-23, 39 of 50 rows were not OK (37 failed and 2 quota blocked). The full window had 2,076 candidate pairs. Run status excluded 729 and a model change excluded one. Evaluated pairs begin on 2026-10-21.

From 2026-10-25 to 2026-10-29, 147 OpenAI rows were quota blocked, accounting for 177 excluded consecutive pairs. On 2026-11-10 we changed which model we ask in our OpenAI collection. The analysis excludes the 50 pairs spanning 2026-11-09 and 2026-11-10. The two periods also differ in average list length.

Claude had 16 failed originals on 2026-10-24 and 32 consecutive pairs excluded. The 16 retries are used for the same-day comparison. Every original failed, leaving zero evaluable same-day pairs. Perplexity had one quota-blocked row on 2026-09-30 and one failed row on 2026-10-21, accounting for four excluded consecutive pairs. A candidate consecutive pair is excluded if either row is not OK.

The window excludes 168 nationwide and 112 single-business pilot rows per engine. Claude's recorded model string changed form on 2026-10-24. Its normalized model identifier stayed the same after removing the prefix, version suffix and date stamp. Gemini recorded two model identifiers. The earliest nonempty model strings appear on 2026-10-08 for Perplexity, 2026-10-14 for Claude and OpenAI, and 2026-10-15 for Gemini. Missing model strings cannot establish a model match or change.

Cross-check and reproduction

We matched 8,611 OK retained segment rows, including OK retries, from 2026-09-28 to 2026-11-23 to the dataset by source filename. The cleaned name counts and the concatenated letters and digits agreed for every matched row. This comparison does not verify each name boundary.
