What this file does not claim

  • No ranking. It shows whether the business was named, not where it stands.
  • No prediction. It does not say what the engines will answer tomorrow.
  • One dated sample per run: 3 identical requests per engine on one UTC date.
  • API channel only. It does not measure what a person sees in a logged-in app.
  • A name in an answer is not a recommendation to hire.
