From 2026-09-27 to 2026-11-22, we asked OpenAI, Gemini, and Anthropic the same local question each day using API calls as part of our residential roofing collection. The table pools 420 saved API answers from the three engines that were marked OK. A mention means the saved answer text contains the word or a form of it. A row can cover several related words. For example, the insurance row counts an answer that uses the word "insured" or "bonded." If both appear in the same answer, it counts once in that row. Each percent uses the full set of saved roofing answers in the table.

The table counts words. It cannot show whether a statement in an answer is true or whether a topic is useful when you choose a roofer. The word "warranty" can appear even in a sentence that says the warranty details are unknown. The word "estimate" can appear without a price or a written quote. An answer with words about both warranties and estimates can count in both rows. The engines can use different wording, and the table combines their answers without a separate count for each engine.
